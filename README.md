# FitPlan

FitPlan is a workout planning web app built with Vue 3, Vite, and Vue Router.

## Current Status

The project currently includes:

- Vue 3 and Vite setup
- Shared application layout
- Vue Router navigation
- Welcome page
- Basic route structure for future authentication pages

## Planned Features

- Supabase email sign up
- Supabase email login
- Protected dashboard route
- Logout flow
- Workout dashboard
- Exercise routine display

## Tech Stack

- Vue 3
- Vite
- Vue Router
- JavaScript
- CSS
- Supabase planned
